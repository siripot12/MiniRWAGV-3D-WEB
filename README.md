# AGV Factory Showroom

เว็บโชว์รูมโรงงาน 3 มิติแบบ local ใช้ Vite, React, TypeScript, Three.js, React Three Fiber และ Drei ไม่มี backend และไม่เชื่อมต่อ AGV จริง

## เปิดใช้งาน

ต้องมี Node.js 22.12+ (หรือ 20.19+) จากนั้นในโฟลเดอร์โปรเจกต์:

```sh
npm ci
npm run dev
```

เปิด http://127.0.0.1:5173/ — เซิร์ฟเวอร์ผูกกับ loopback เท่านั้น ยังไม่เผยแพร่ออนไลน์

```sh
npm run build
npm run preview
npm test
node check-browser.mjs
```

คำสั่งสุดท้ายทดสอบผ่าน Microsoft Edge ที่ติดตั้งในเครื่อง ใช้ dev server ที่เปิดอยู่ และบันทึกภาพลง test-results/

## การใช้งาน

- เริ่ม/พัก/เล่นต่อ: AGV วิ่งวงรอบ A → B → A และจอดแต่ละสถานี 2 วินาที
- ความเร็ว 0.5×, 1×, 1.5×; 1× เท่ากับ 0.35 เมตร/วินาทีในสเกลจำลอง
- ไฟ AGV: ปรับวัสดุเรืองแสงสีแดง/เขียวและไฟส่องใกล้ตัวรถ
- ไฟโรงงาน: สลับกลางวัน/แสงสลัว
- ภาพรวมและใกล้ตัวรถ: ลากหมุน เลื่อนซูม หรือใช้ touch/pinch; กล้องติดตามเคลื่อนตามรถอัตโนมัติ
- เริ่มต้นใหม่: คืนสถานี A, หยุดรถ, กล้องภาพรวม, ความเร็ว 1× และเปิดไฟทั้งหมด
- เมื่อเปลี่ยนแท็บ การเคลื่อนที่หยุดชั่วคราวและไม่มีการชดเชยระยะที่ผ่านไป

## ทรัพยากรและโครงสร้าง

- public/models/agv.glb: ส่งออกด้วย Blender MCP จาก ../output/AGV/AGV_refined.blend เฉพาะ collection AGV_Reference_Model รวมวัสดุและสายไฟ ไม่รวมฉากสตูดิโอหรือโมเดลเก่า
- public/models/factory.glb: ส่งออกจาก ../Factory.blend ใช้พื้น สถานี A/B ทางแยก และขอบโรงงาน แล้วจัดสเกลและตำแหน่งเป็นโชว์รูมบนเว็บ
- src/simulation.ts: แหล่งข้อมูลตำแหน่งสถานีและเส้นทางเดียวกัน พร้อม state machine ที่ทดสอบแยกได้
- src/scene.tsx: โรงงาน โมเดล ไฟ กล้อง และล้อที่หมุนตามระยะทาง
- src/main.tsx: แผงควบคุม React และ loading/error states
- export_agv.py: สคริปต์ส่งออกซ้ำผ่าน Blender MCP ขณะเปิดไฟล์รุ่นปรับปรุง ต้นฉบับ Blender ไม่ถูกบันทึกทับ

โมเดลใช้ glTF Y-up (AGV ด้านหน้าคือ +Z, แกนล้อ local X) และ wheel pivots มี extras.part = wheelPivot; วัสดุไฟแยกจากตัวถัง การแปลง modifiers และเส้น curve เป็น mesh ทำเฉพาะสำเนาชั่วคราว

โมเดล GLB ฟอนต์ และ dependency ทั้งหมดโหลดจากเซิร์ฟเวอร์เดียวกัน ไม่มี CDN, HDRI ภายนอก, Draco decoder ภายนอก หรือ API ภายนอกขณะใช้งาน

## ข้อจำกัด

ขนาดเป็นการประมาณจากภาพ ไม่ใช่ digital twin สำหรับวิศวกรรม ไม่มีฟิสิกส์หรือระบบชนเต็มรูปแบบ สิ่งกีดขวางจัดไว้นอกเส้นทางสาธิต ต้องใช้เบราว์เซอร์ที่รองรับ WebGL 2 และประสิทธิภาพขึ้นกับ GPU

หากเปลี่ยนโมเดล ให้คงชื่อวัสดุ Red LED / Green status LED และ metadata ของ wheel pivots ไว้ เมื่อส่งออกใหม่ให้รีโหลดเว็บเพื่อโหลด GLB ใหม่
